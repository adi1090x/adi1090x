### About

I'm an independent Linux developer and the creator of [**Archcraft**](https://archcraft.io) - an Arch Linux-based distribution focused on delivering a refined, lightweight, and customizable desktop experience.

For several years, I've been independently developing, maintaining, and expanding the Archcraft ecosystem. My work spans Linux distributions, window managers, Wayland compositors, shell scripting, and desktop customization.

I'm particularly interested in building complete Linux desktop experiences where functionality meets thoughtful design. My work focuses on practical tools, efficient workflows, system integrations, and cohesive interfaces - creating environments that are not only visually appealing but genuinely useful in everyday computing.

### What I Do

- **Linux Development** — Building, maintaining, and customizing Linux distributions and system components.
- **Desktop Experience Design** — Creating cohesive, productivity-focused desktop setups that balance functionality, usability, and aesthetics.
- **Window Managers & Wayland** — Developing configurations, workflows, and integrations for modern Linux desktop environments.
- **Shell Scripting & Automation** — Building utilities, system tools, and workflow automation using shell scripting.
- **Open Source Development** — Creating and maintaining projects, tools, and resources for the Linux community.

### Design Philosophy

I believe a good Linux desktop should be more than a collection of attractive themes and visual effects.

My approach to desktop development is built around three principles:

- **Functionality** — Every component should serve a purpose and contribute to the overall experience.
- **Usability** — Workflows should be intuitive, efficient, and designed around everyday tasks.
- **Aesthetics** — Visual consistency and thoughtful design should complement functionality, not compete with it.

The goal is simple: build desktop experiences that look good, work well, and make everyday computing more enjoyable.
